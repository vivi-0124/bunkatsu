# Bunkatsu - E2Eテスト観点（テストシナリオ）

現在の実装（機能別パッケージ構成、Vue 3 + Vuetify + Pinia + Hono API）に基づいた、E2Eテストで担保すべき観点とシナリオの網羅的なリストです。
Playwright や Cypress などの E2E テストツールを導入する際のテストケース仕様としてご活用いただけます。

---

## 1. 認証・認可 (Authentication & Authorization)
**対象機能**: `features/auth`, ルーティングガート

- **未ログイン時のアクセス制御**
  - `/dashboard` などの要認証ページにアクセスした際、ルート (`/`) にリダイレクトされること。
- **ログインフロー**
  - トップページ (`/`) から Google アカウント（または通常ログイン）で正常にログインでき、`/dashboard` に遷移すること。
- **ログアウトフロー**
  - ヘッダーまたはサイドバーのログアウトボタンから正常にログアウトでき、トップページに遷移すること。
  - ログアウト後、ブラウザの「戻る」ボタンで `/dashboard` に戻ってもデータが表示されず、リダイレクトされること。
- **管理者権限制御 (RBAC)**
  - `role: user` のアカウントで `/dashboard/admin` にアクセスした際、エラー画面または `/dashboard` にリダイレクトされること。
  - `role: admin` のアカウントで `/dashboard/admin` 系ページが正常に表示されること。

## 2. ダッシュボード (Dashboard)
**対象機能**: `features/dashboard/pages/DashboardPage.vue`

- **サマリー表示**
  - ログイン後、現在の月の総収入、総支出、残額などのサマリー情報が正しく計算されて表示されていること。
- **ナビゲーション**
  - サイドバーから「固定費管理」「月次明細」「管理者設定」などの各機能へ正しくルーティングされること。

---

## 3. 分割払い・固定費管理 (Fixed Costs)
**対象機能**: `features/fixed-costs`

- **一覧表示とフィルタリング**
  - 登録済みの固定費データがテーブル（モバイルの場合はカード形式）で表示されること。
  - **検索**: 項目名で検索し、部分一致で絞り込まれること。
  - **ステータスフィルタ**: 「すべて」「開始前」「支払い中」「完済」のフィルタが正しく機能すること。
- **CRUD操作**
  - **追加**: 必須項目（項目名、開始月、月額）を入力して新規追加でき、一覧に反映されること。
  - **編集**: 既存の固定費を選択し、月額や総支払回数などを変更して保存でき、一覧の進捗率や残り金額が再計算されること。
  - **削除**: 削除ダイアログで確認後、正常に削除され、一覧から消えること。
- **データ連携 (CSV)**
  - テンプレートCSVが正常にダウンロードできること。
  - 規定フォーマットのCSVをアップロードし、データが一括でインポート（一覧に反映）されること。
  - 現在のデータがCSVとしてエクスポートできること。

---

## 4. 月次明細 (Monthly Records)
**対象機能**: `features/monthly-records`

- **月次ナビゲーション**
  - デフォルトで現在の「年月」が選択されていること。
  - 前月・次月ボタンをクリックした際、URLのクエリパラメータまたは状態が更新され、その月のデータに切り替わること。
- **計算ロジック検証**
  - 「支出」と「収入」の合計額、および「残額（Income - Payment）」が正しく計算されていること。
  - チェックボックスの状態（未払い・支払済み）に応じて「残りの支払額」が動的に再計算されること。
- **CRUD操作（単発・繰り返し）**
  - **追加**: 支出/収入を追加できること。「毎月繰り返す」にチェックを入れた場合、翌月以降のページでも該当項目が表示されること。
  - **編集（スコープ）**: 繰り返し項目を編集する際、「この月のみ変更」と「以降もすべて変更」の分岐が正しく機能すること。
  - **削除（スコープ）**: 同様に、削除時に「この月のみ」「以降すべて」の削除スコープが機能すること。
- **一括操作 (Bulk Actions)**
  - 複数の支出項目を選択し、「選択した項目を支払済みにする」アクションが正常に動作すること。
  - 複数の項目を選択して「一括削除」できること。
- **テンプレート展開**
  - 月初などに「テンプレートから生成（自動生成）」ボタンを押し、設定済みの繰り返し項目（固定費やサブスク）がその月の明細として展開されること。

## 5. 管理者機能 (Admin)
**対象機能**: `features/admin`

- **ユーザー一覧表示**
  - システムに登録されているユーザーが一覧表示されること。
- **ユーザー管理操作**
  - 特定のユーザーの権限（`admin` / `user`）を変更できること。
  - 特定のユーザーを削除または凍結（実装されている場合）できること。
  - （自分自身のAdmin権限を外そうとした際などに警告やブロックがあるか等のエッジケース）

## 6. 全体共通・非機能要件 (Global & Non-functional)
- **通知 (Snackbar)**
  - データ保存成功時やエラー時に、画面下部（または右上）にスナックバーメッセージが適切な色（緑・赤）で表示されること。
- **レスポンシブデザイン**
  - 画面幅をスマホサイズに縮小した際、サイドバーがハンバーガーメニューに格納されること。
  - `FixedCostsPage` や `MonthlyPage` のデータテーブルが、スマホ幅ではカード形式などのモバイル向けビューに自動的に切り替わること。
- **ローディング状態**
  - API通信中にボタンのスピナーやスケルトンスクリーンが表示され、二重送信が防止されていること。
